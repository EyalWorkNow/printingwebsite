# ניתוח pix.co.il ואפיון יעד לדפוס

נבדק ב-24.11.2026. המקורות: מפת האתר (191 כתובות), ה-HTML של העמודים, נתוני ה-RSC וה-GraphQL שנטענים בעמוד, קובצי ה-JS, וצילומי מסך מדפדפן אמיתי.
לא בוצעה רכישה, ולא נשלח שום טופס.

## 3. עמוד מוצר: שני סוגים

`attribute_set_name` קובע את סוג העמוד:

**א. Template Picker** (למשל כרטיס ביקור):
- Hero של הקטגוריה.
- גריד של **תבניות עיצוב**: לכרטיס ביקור יש 170 תבניות, ולכל תבנית יש וריאציות צבע (עיגולי צבע מתחת לתמונה).
- סרגל צד דביק עם האפשרויות (dropdown עם אייקון), מחיר כולל, מחיר ליחידה, "למחירון המלא" ו"לזמני ייצור ומשלוח".
- שני כרטיסים קבועים בראש הגריד: "לא מעוניינים בתבנית? עצבו בעצמכם" ו"להעלות עיצוב מוכן".
- שינוי אפשרות **מסנן את התבניות**: בכל תבנית יש `options_config` שמציין לאילו ערכים היא מתאימה.

**ב. Default / Multi Item** (חולצה, ספל, פלייר):
- תמונה, תיאור, "מחיר ל-1 יח׳", "מינימום כמות".
- שני כפתורים: **לעצב אונליין** ו-**להעלות עיצוב מוכן**.

**שני הכפתורים פותחים ויזרד במסך מלא:**
1. בחירת מאפייני מוצר (צבע מוצר)
2. בחירות נוספות (פורמט ההדפסה, עם אייקונים)
3. בחירת כמות: טבלה של כמות, סה״כ ומחיר ליחידה, ושורה של "התאמה אישית"
4. בהעלאה בלבד: הוראות להעלאת עיצוב מוכן

בתחתית כל שלב יש פס קבוע עם `סה"כ | ל-N יח׳ | מחיר ליח׳ | כולל מע״מ` וכפתור **המשך**.
אפשרויות שמסומנות `is_after_editor` (נייר, למינציה, מידות) נבחרות **אחרי** העורך: "כל הכבוד! העיצוב מוכן, אפשר להוסיף מידות וצבעים".

**מתחת לכל מוצר:**
- 4 כרטיסי "פרטים על המוצר"
- באנר FIX IT
- "מוצרים נוספים שיעניינו אותך"
- טקסט SEO ארוך

## 4. מודל הנתונים של אפשרויות המוצר (הלב של המערכת)

```
Product { sku, name, attribute_set, editor_type, price_tiers[{quantity, price}],
          advanced_inventory{min_qty, max_qty, qty_increments, allow_custom_qty, predefined_qty_steps[]},
          production_time[{label, business_days}], options[], option_rules[], option_templates[], option_helpers[] }
Option  { option_id, sku, title, option_type, parent_option_id, is_after_editor, values[] }
Value   { option_type_id, title, is_default, is_enabled, icon|color, tier_prices[{quantity, price}],
          min_pages/max_pages/price_per_page (חוברות) }
Rule    { when option X ∈ values → hide option Y values }      // למשל ריבועי ⇒ מסתיר שוכב/עומד
Template{ uid, name, thumbnail, theme_color, options_config[{option_id, values}], thumbnails per config }
```

**ערכי `option_type`:**
- `layout`
- `is_size`
- `is_color` (צבע המוצר)
- `is_print_color`
- `is_pages` (צדדי הדפסה, עמודים)
- `multi_pages_and_sizes` (מיקום ההדפסה בחולצה)
- `multi_quantity` (כמות לכל מידה: S×5, M×3)
- `user_defined_pages`
- `size_with_cover`, ‏`cover_type`
- `logo_upload`

**נוסחת המחיר, כפי שאומתה מול האתר:**
```
unit  = round2( base_tier(q) + Σ selected_value.tier(q) )     // tier = המדרגה הגבוהה ביותר ≤ q
total = unit × q × 1.18
```
**אימות:**
- **כרטיס ביקור, 100 יח׳:** מידה 1.11 + נייר 0.111 + למינציה 0.037 = 1.26. ‏1.26 × 100 × 1.18 = **148.68 ₪**, בדיוק כמו באתר.
- **כרטיס ביקור, 300 יח׳:** 0.4094 + 0.1068 + 0.0356, אחרי עיגול 0.55. ‏0.55 × 300 × 1.18 = **194.70 ₪**, בדיוק כמו באתר.
- **חולצה, 1 יח׳:** בסיס 23.872 + כיס קדמי 10.848 = 34.72. ‏34.72 × 1.18 = **40.97 ₪**, בדיוק כמו באתר.

**כמויות:**
- מדרגות קבועות, למשל 100/300/500/1000/1500/5000/10000 בכרטיס ביקור, ו-36/72/… בספל.
- כמות חופשית לפי `qty_increments`: בכרטיס ביקור כפולות של 50, בין 100 ל-10,000.

**זמני ייצור:**
- 5 סוגים: אקספרס (1 יום עסקים), מהיר (3), רגיל (5), חסכוני (7), ייצור מיוחד (12).
- כל מוצר מציע 2–3 מהם.
- מגירת "זמני ייצור" מציגה **תאריך הגעה משוער** בפועל ("בין 25 ל-29 לנובמבר").

## 6. שירותים נלווים

- **FIX IT** (‏70 ₪ למוצר) כולל שלושה מסלולים:
  - עדכון פרטים בעיצוב קיים
  - תיקון קובץ בגודל או בפורמט שגוי
  - התאמת תבנית מהאתר

  הזרימה: בוחרים מוצר, כמות וגודל, מעלים קבצים, מוסיפים הערות (שדה חובה), ומוסיפים לעגלה.
- **הנחיות לקובץ מוכן:**
  - PDF וקטורי, 300dpi, עד 25MB
  - פונט 8pt ומעלה, קווים 0.5pt ומעלה
  - Bleed, ‏Trim (סטייה של 1–2 מ״מ), ‏Safe area
  - אין צורך בסימני חיתוך
  - קובץ עזר להורדה לכל מוצר
- **שגיאות קובץ שהמערכת מזהה:** "מידות העמוד גדולות מדי", "לא הצלחנו לקרוא את הקובץ".
- **העלאת לוגו:** מומלץ 300DPI. הלוגו מוצג על תמונות המוצרים (‏logo-preview).

## 8. תוכנית בנייה מומלצת

1. **מודל נתונים:**
   - `Product`, ‏`Option`, ‏`Value` עם `tiers` לכל ערך, `Rule`, ‏`ProductionTime`, ‏`qty{min,max,step,presets}`.
   - פונקציה אחת בשם `price(product, selections, qty)` לפי הנוסחה בסעיף 4, עם בדיקות שמשחזרות את שלוש הדוגמאות.
   - הצ׳אט ישתמש **באותה** פונקציה.
2. **קטלוג וקטגוריות:** נתיבים `/[slug]` למוצר ולקטגוריה, מגה-תפריט, וכרטיסי "החל מ-".
3. **עמוד מוצר עם ויזרד:** אפשרויות, כמות, העלאה עם הנחיות, ופס מחיר דביק. אחר כך מחירון וזמני ייצור במגירה.
4. **עגלה מרובת פריטים וקופה בשלושה שלבים.** התשלום בהתחלה טלפוני, ואחר כך ספק סליקה ישראלי.
5. **ניהול:** עריכת מחירים ואפשרויות (היום הם בקוד), והזמנות עם פריטים מרובים.
6. **בהמשך:** תבניות ועורך (פרויקט בפני עצמו), חשבון לקוח, נקודות חלוקה, מוקאפים מצולמים.

> לבנות מערכת משלנו ולא להעתיק תוכן, תמונות, תבניות או מיתוג של pix. הנוסחה והמבנה הם דפוסי מסחר אלקטרוני מקובלים.
